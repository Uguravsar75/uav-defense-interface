# UAV Defense Interface | Teknofest

> Teknofest Yarışması — İnsansız Hava Aracı Savunma Sistemi Arayüzü

## Overview
A structured user interface developed for a UAV (Unmanned Aerial Vehicle) defense system as part of the Teknofest competition. Built within a cross-functional engineering team, focusing on usability, accessibility, and modular front-end components.

## Features
- 🖥️ Structured and modular UI components for defense system operations
- ♿ Accessibility-focused design principles
- 🔧 Modular architecture for scalable interface development
- 👥 Collaborative development within a cross-functional engineering team
